01
The Problem

Turning website information into usable data

Product information is often distributed across multiple website pages, making manual collection time-consuming and difficult to scale.

For example, an online bookstore may display basic product information on catalogue pages, while additional details are only available through individual product pages.

This project explores how Python can automate the collection of website information and transform unstructured HTML into structured datasets suitable for analysis.

02
Data Source

Books to Scrape

The project uses Books to Scrape, a website designed for practising web scraping techniques.

Its catalogue structure provides an opportunity to practise collecting product information, navigating pagination and extracting additional details from individual product pages.

Natural Language Processing

Building a book recommendation engine

The collected book information was also used to explore content-based recommendation techniques.

Book text features were combined and transformed into numerical vectors using TF-IDF.

Cosine similarity was then used to compare book representations and identify titles with similar textual characteristics.

The relatively low similarity scores highlight the limitations of using short product descriptions and catalogue information for recommendations.

A potential improvement would be to incorporate richer descriptions, additional metadata and more advanced text representations.

08
Engineering Challenges

Lessons from building the pipeline

Website data is rarely analysis-ready.

Extracted HTML requires cleaning, transformation and validation before it can support meaningful analysis.

Pagination makes data collection scalable.

Automating navigation across catalogue pages reduces the need to collect information manually.

Data consistency matters.

Ensuring extracted fields have consistent lengths and formats is essential when constructing Pandas DataFrames.

Data collection enables downstream analytics.

The same structured dataset can support exploratory analysis, reporting and machine-learning applications.
